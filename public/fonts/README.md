# PDF用の日本語フォント

`MPLUS1p-Regular.ttf`は、日本語用のM PLUS 1p Regularです。
PDF保存ボタンを押したときに同一オリジンから読み込み、文字欠けを防ぐためフォント全体をPDFに埋め込みます。

- 配布元：https://github.com/google/fonts/tree/main/ofl/mplus1p
- 取得元：https://raw.githubusercontent.com/google/fonts/main/ofl/mplus1p/MPLUS1p-Regular.ttf
- ライセンス：SIL Open Font License 1.1（同梱の`OFL-MPLUS1p.txt`）
- 取得日：2026-10-20

フォントは改変せずに同梱しています。アプリの初期表示では取得しません。
